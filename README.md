# מאמן כדורגל – אפליקציה לאנדרואיד

אפליקציית האנדרואיד של **מאמן כדורגל** (soccer-coach-1.web.app): אישורי הגעה לאימונים ומשחקים, זימונים, ציונים וסטטיסטיקה.

## הורדה

👉 **[הורדת הגרסה האחרונה (APK)](https://github.com/denizvek/soccer-coach-app/releases/latest/download/soccer-coach.apk)**

## התקנה

1. פותחים את הקובץ שירד.
2. מאשרים "התקנה ממקורות לא ידועים" (פעם אחת).
3. לוחצים "התקנה". אם מופיעה אזהרה של Google Play Protect – בוחרים "התקן בכל זאת".
4. נכנסים עם המייל והסיסמה שנרשמתם איתם (או נרשמים בקישור שקיבלתם מהמאמן).

המאגר הזה מכיל רק את קובץ ההתקנה.
